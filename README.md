# Enterprise Monitoring Suite

## Project Overview

This repository contains four end-to-end monitoring projects demonstrating infrastructure monitoring, centralized logging, alerting, distributed tracing and scalable monitoring architectures.

The projects are built using Prometheus, Grafana, Elasticsearch, Logstash, Kibana, Alertmanager and Jaeger running on Docker Compose.

---

# Objectives

- Infrastructure Monitoring
- Metrics Collection
- Dashboard Visualization
- Centralized Logging
- Alert Management
- Distributed Tracing
- Monitoring Scalability
- High Availability Concepts
